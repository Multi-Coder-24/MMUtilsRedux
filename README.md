# Multicoder's Minecraft Mod Management Utility (MMUtils)
This project is a simple Minecraft mod development management application for developers to keep track of progress of their projects.
Using this simple application mod developers can keep up to date on their own development or for teams to view notes and development
from team members and help keep track of what version is published and where. 
This app is freeware however any monetary gift is greatly appreciated.

## This project is currently in active development and we cannot put a timeframe on when the first release will be made.

### Key Notes
- Java Version: 25
- Tested OS: Windows
- Bundles External Libraries: Yes
- Libraries Bundled: Google GSON, Apache Log4j Core
- Bundled Library Versions; GSON:2.14.0, Log4j-Core:2.26.0
